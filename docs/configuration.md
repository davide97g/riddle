# Every setting

Declared once, in `riddle/config.py`. `.env` is read by Python, so a tool
picks up the same configuration a service does. A variable already in the
environment beats `.env`, which is what makes `RM2_SSH_HOST=rm2 riddle
device build` work for a one-off; `riddle config` prints where every value
came from.

`.env.example` is **generated** — `riddle config --write-example` — with
every line commented out at the code's own default. A template that sets
nothing cannot drift from the code. `riddle config --check` catches a key
nothing reads, a value of the wrong type, and a stale example file.


## device access

| variable | default | read by | |
|---|---|---|---|
| `RM2_HOST` | `10.11.99.1` | nothing: for logging in by hand | The address every reMarkable exposes with USB web interface on. For logging in by hand; the code uses RM2_SSH_HOST. |
| `RM2_USER` | `root` | nothing: for logging in by hand | For logging in by hand. |
| `RM2_PASSWORD` | `unset` | nothing: for logging in by hand | Printed on the tablet under Settings > Help > Copyrights and licenses, and regenerated by major firmware updates. For logging in by hand; nothing here reads it. |
| `RM2_SSH_HOST` | `rm2` | the loop, the tools | The ssh alias the diary talks to. Define it in ~/.ssh/config, ideally with a key, so no password is ever needed. |
| `RM2_WIFI_HOST` | `unset` | the loop, the tools | The tablet's address over wifi, if it has one. Only `riddle link` uses it, to probe both routes. |
| `RIDDLE_AGENT` | `/home/root/riddle/riddled` | the loop, the tools | Where the agent lives on the tablet. |

## the diary

| variable | default | read by | |
|---|---|---|---|
| `RIDDLE_NOTEBOOK` | `Notebook` | the loop | Which notebook to announce at startup. Ink lands in whatever page is actually on screen; this is a statement of intent. |
| `RIDDLE_PAUSE_MS` | `3000` | the loop | Idle time after a pen lift before the diary answers. |
| `RIDDLE_OPENAI_MODEL` | `gpt-4.1-mini` | the loop | Which model answers. It has to be able to see -- the page is attached to the turn -- and it has to be quick, because the reply is two dozen words and the pause is already over. |
| `RIDDLE_OPENAI_KEY` | `unset` | the loop | The OpenAI API key. Put it in .env, which is gitignored and must be chmod 600. |
| `RIDDLE_OPENAI_URL` | `https://api.openai.com/v1` | the loop | Where that API lives. Anything OpenAI-compatible that takes an image works, which is how a local model would be dropped in. |
| `RIDDLE_MAX_WORDS` | `22` | the loop | How long a reply may be. A page is small and the pen is slow. |

## the hand

| variable | default | read by | |
|---|---|---|---|
| `RIDDLE_FONT_BODY` | `futural` | the loop, `riddle write` | The hand for longer replies. A .jhf in the fonts directory is Hershey; a .ttf is skeletonised into a joined hand. |
| `RIDDLE_FONT_ACCENT` | `DancingScript` | the loop, `riddle write` | The hand for short replies and *emphasis* runs. |
| `RIDDLE_INK_HEIGHT` | `72` | the loop, `riddle write` | Cap height of the diary's writing, in screen pixels. |
| `RIDDLE_PRESSURE` | `3200` | the loop, `riddle write` | How hard the injected nib presses, 0-4095. Thicker ink, and xochitl is likelier to believe it. |

## the page you speak into

| variable | default | read by | |
|---|---|---|---|
| `RIDDLE_DB` | `riddle.db` | the voice server | The store both halves write. Relative paths hang off var/. |
| `RIDDLE_WEB_HOST` | `127.0.0.1` | the voice server | Loopback on purpose: `riddle voice share` is what exposes it, and it does so behind a real certificate. |
| `RIDDLE_WEB_PORT` | `8765` | the voice server | The port the page is served on. |
| `RIDDLE_WEB_DIR` | `apps/web/dist` | the voice server | The built client. Without it the server serves a stub page and the api still works. |
| `RIDDLE_WEB_DEBUG` | `1 to enable` | the voice server | Log every request line. |
| `RIDDLE_WEB_PASSWORD` | _(unset)_ | the voice server | One password in front of the page. Empty means no gate, which is right on loopback and wrong the moment the port is published. |
| `RIDDLE_ASR_MODEL` | `ggml-parakeet-tdt-0.6b-v3-q8_0.bin` | the voice server | The speech model, fetched once by hand. Relative paths hang off var/models. |
| `RIDDLE_ASR_THREADS` | `4` | the voice server | Threads for one parakeet run. Runs are serialised anyway: two of them share one Metal context and make each other slower. |
| `RIDDLE_VAD_FLOOR` | `0.012` | the voice server | The quietest thing the gate will call speech. Too low and the fridge is transcribed; too high and quiet speech is lost. |
| `RIDDLE_VAD_HANG_MS` | `700` | the voice server | Silence before an utterance is considered finished. Too short and sentences are cut mid-clause. |
| `RIDDLE_VAD_MAX_MS` | `20000` | the voice server | Forced cut. Somebody is monologuing. |
| `RIDDLE_AUDIO_KEEP_DAYS` | `7` | the voice server | How long recordings of your room stay on disk. 0 keeps them forever, which is a decision worth making on purpose. |

## the client's build

| variable | default | read by | |
|---|---|---|---|
| `RIDDLE_SERVER` | `derived` | `riddle web` | Where the dev server proxies /api and /ws. Derived from the host and port unless you set it. |
| `RIDDLE_TAILNET` | `1 to enable` | `riddle web` | Dev mode behind `tailscale serve`: hot reload has to dial 443 over wss, because tailscale terminates the TLS. |

## safety

| variable | default | read by | |
|---|---|---|---|
| `RIDDLE_ALLOW_DRAW` | `1 to enable` | anything that touches the tablet | Standing permission to put ink on whatever page is open. Leave it unset and pass --yes per command instead. |
| `RIDDLE_ALLOW_SNAP` | `1 to enable` | anything that touches the tablet | Standing permission to read the tablet's screen out of another process's memory. Same advice. |

## Not settings

`RIDDLE_ROOT` and `RIDDLE_VAR` override where the checkout and its state
directory are found; `riddle.paths` works them out for itself otherwise.

The client's build-time variables, `RIDDLE_SERVER` and `RIDDLE_TAILNET`,
are injected into `bun` by `riddle web` rather than being read from your
shell. `RIDDLE_SERVER` is derived from the host and port by default, so
moving the port cannot silently break the dev proxy.
