Set up riddle

riddle is three things you own: a reMarkable 2, a small server at home that talks to it, and the app on your iPhone, iPad or Mac. The app is the easy part. This page is the other two.

What you need

  • A reMarkable 2. The reMarkable 1 is experimental; the Paper Pro and Paper Pro Move are not supported. Why.
  • A server that stays on, on the same network as the tablet: a mini PC, a Raspberry Pi 4 or 5, a NAS that runs Docker, or a Mac.
  • An OpenAI API key, or a key for any compatible model that can read images. A reply costs a fraction of a cent.

1. Install the server

On the server (Linux or macOS):

curl -fsSL https://raw.githubusercontent.com/davide97g/riddle/main/scripts/install.sh | bash

It downloads riddle and starts riddle setup, which asks one thing at a time: the tablet's address (USB is 10.11.99.1; on wifi, see Settings > Help > Copyrights and licenses, where the root password is too), your API key, a password for the app, and whether to start riddle at boot. Nothing is drawn on the tablet during setup.

Prefer Docker? docker compose -f deploy/docker/compose.yml up -d from a clone: the container guide.

3. Connect the app

Open riddle, type the address and the password you chose during setup, and tap Agree and Connect. That is all the app ever needs.

4. Write

Open a notebook on the tablet. Write a question. Stop. Wait three seconds. Your ink fades, and the diary writes back in its own hand.

Before the first page, take a backup of the tablet: riddle backup create. The diary writes on whatever page is open.
